# 指标管理系统：Figma 低保真线框图（V0.1）

## 1. Figma 文件

[打开“指标管理系统｜低保真线框图 V0.1”](https://www.figma.com/design/tVsjQFZLqV45x7D6mXSw6N)

文件中的“01 核心线框图”页面包含三个 1440 × 1024 桌面端页面：

1. 指标管理人员：任务详情与进度。
2. 部门填报人员：填报工作台。
3. 数据查看人员：数据查看首页。

## 2. 已落实的产品规则

- 系统只有指标管理人员、部门填报人员和数据查看人员三类业务角色。
- 部门填报人员提交成功后直接完成，不进入审核流程。
- 已提交数据不能直接覆盖；指标管理人员开放更正后才能生成新版本。
- 数据查看人员只能查看被授权部门的数据。
- 三类角色登录后看到不同菜单和首页。

## 3. 页面设计重点

### 3.1 任务详情与进度

- 展示参与部门、已完成、填报中和已逾期数量。
- 展示任务周期、指标数量和当前状态。
- 以部门为单位查看进度和最后更新时间。
- 保留催办、查看数据和归档入口。

### 3.2 填报工作台

- 明确当前部门、任务周期和截止时间。
- 突出当期值、当年累计值两个核心填报字段。
- 保留导入、保存草稿和提交三个主要操作。
- 明确提示“提交后直接完成，不能自行修改”。
- 提交前显示未填写数量和校验规则。

### 3.3 数据查看首页

- 页面顶部首先显示授权部门筛选条件。
- 展示授权部门数、可查看指标数、已完成任务和数据更新时间。
- 展示趋势、部门完成情况和近期指标数据。
- 只提供查看、筛选和导出操作，不提供任何编辑入口。

## 4. Figma 实现方式

- 页面由可编辑的 Frame、Text、Vector 和组件实例构成，不包含整页截图。
- 使用 Auto Layout 组织页面结构。
- 按钮和导航使用 Simple Design System 的组件实例。
- 背景、文字、边框和圆角使用设计系统变量绑定。
- 复用的统计卡片制作成了本地组件。
- 中文字体使用 Noto Sans SC，作为现有网页字体栈中 PingFang SC 的可用替代。

## 5. 本轮评审重点

这一轮只评审信息架构和交互入口，不评审最终配色与视觉细节。需要重点确认：

1. 每类角色进入页面后，是否能立即找到最重要的工作。
2. 任务详情中的进度信息是否足够支持催办和异常处理。
3. 填报工作台的字段是否覆盖实际填报需要。
4. 数据查看首页的统计信息是否是查看人员最关心的内容。
